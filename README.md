# vision-serve

A production-grade inference service for deep neural networks, built from scratch as part of a transition into ML/AI engineering.

🚧 **Work in progress.** See commit history for development log.

## Stack (planned)

- Python 3.12, FastAPI, PyTorch, ONNX Runtime
- Docker, Kubernetes (EKS)
- Prometheus + Grafana
- AWS (S3, ECR, EKS)

## Development

This project uses a [Dev Container](https://containers.dev/) for a reproducible Linux environment. Open in VS Code and run "Reopen in Container."
